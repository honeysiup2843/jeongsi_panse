# 정시 지원 판세도

수능 성적을 **대학별 반영비율로 다시 계산해** 199개 학과를
위험 · 상향 · 소신 · 적정 · 하향 다섯 칸에 배치하는 단일 페이지 웹앱.

같은 성적이라도 대학마다 유리·불리가 갈린다는 것을 눈에 보이게 만드는 것이 목적이다.
예를 들어 수학 반영비율이 43.3%인 서강대와 20%인 숭실대는 같은 학생을 전혀 다르게 평가하고,
영어 4등급은 건국대에서 −0.5%p, 중앙대에서 −8.0%p의 차이를 만든다.

## 기능

- **성적 입력** — 국어·수학·영어·탐구2, 표준점수 / 백분위 / 등급 동시 입력, 선택과목 지정
- **빈칸 자동 추정** — 하나만 넣어도 수능 표준↔백분위 대응 곡선으로 나머지를 채움
- **5단계 보드** — 경계값(%p)을 슬라이더로 직접 조절
- **학과 상세** — 반영비율 스택바, 영역별 취득점수 대비 합격선 눈금, 컷 대비 위치,
  반영비율을 모집요강대로 고쳐 재계산
- **원서 3장 트레이** — 가·나·다군 각 1장
- 계열 / 모집군 / 지역 / 검색 필터, 라이트·다크 테마, 모바일 대응

## 실행

```bash
npm test          # 데이터 불변식 + 엔진 검증 37개
npm run build     # dist/index.html 생성
npm run check     # 둘 다
```

의존성 없음. `node`만 있으면 된다. 빌드 결과 `dist/preview.html`을 브라우저로 열면 확인할 수 있다.

## 구조

`src/data.js`(데이터) + `src/engine.js`(계산) + `src/app.html`(UI)를
`scripts/build.js`가 문자열 치환으로 합쳐 `dist/index.html` 한 장을 만든다.
테스트는 `tests/_load.js`가 **빌드와 같은 순서로** data와 engine을 합쳐 평가하므로,
검증하는 코드와 페이지에 실리는 코드가 동일하다.

작업 규칙·데이터 규칙·엔진 불변식은 [CLAUDE.md](./CLAUDE.md)에 있다.

## 데이터

35개 대학 / 199개 학과. 반영비율·영어 환산·합격선은 공개 보도자료(2025~2026학년도)를
정리한 **참고값**이며, 199개 중 29개만 출처로 확인됐고 나머지는 추정치라 UI에 `추정` 배지가 붙는다.

> 이 도구는 진학 상담을 대체하지 않는다. 실제 지원 전에는 각 대학 모집요강 원문을 확인할 것.
